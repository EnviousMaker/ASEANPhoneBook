# ASEAN Phonebook

C# console application for the ITE1 Final Drill.

This program allows the user to store, edit, and search student contacts from five ASEAN countries using Object-Oriented Programming.

## Countries Supported

| Country                         | Country Code |
|---------------------------------|--------------|
| Federation of Malaysia          | 60           |
| Republic of Indonesia           | 62           |
| Republic of the Philippines     | 63           |
| Republic of Singapore           | 65           |
| Kingdom of Thailand             | 66           |

## Features

- Store unlimited student entries
- Edit any information of an existing student
- Search students by one or more countries (or ALL)
- Results are sorted alphabetically by surname
- Country code validation
